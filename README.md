# A Streaming System for Conventions
Contributions are very welcome. Use this for whatever you like!

Nothing about a single convention is baked in. Names, copy, links, logo, login
background and accent colour all live in the `branding_settings` table and are
edited from the admin panel; `config/branding.php` only holds neutral fallbacks.
